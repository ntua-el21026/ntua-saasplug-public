# AI development record

This archive records AI assistance during coursework development. It links task prompts to the reported changes, commands, checks, and limitations. The logs preserve original course paths and project-management references. Some destinations require course or repository access. Use the [architecture overview](../architecture-summary.md) and [test guide](../../tests/README.md) for current project instructions.

| Record | Contents |
| --- | --- |
| [Original development instructions](original-development-instructions.txt) | Historical copy of the coursework repository's original `AGENTS.md` |
| [Prompt log](prompt-log.md) | Chronological index of the development record |
| [Task prompts](prompts/README.md) | Preserved staged implementation instructions |
| [Run reports](codex-runs/README.md) | Reported implementation actions, checks, and limitations |
| [Supplementary ChatGPT records](prompts_chatgpt/prompts/README.md) | Additional prompt provenance |

An invocation prompt records what was entered for a run. A canonical task prompt records the version-controlled instruction referenced by that invocation. The [verification history](../final-verification.md) preserves the scope of the reported validations.
