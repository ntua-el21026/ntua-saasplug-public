# Assignment references

The teaching brief set the assessed workflows and scope. The teaching SRS and supplied Visual Paradigm model and PlantUML exports illustrated domain concepts and design notation. Those instructor materials are external references. Obtain the matching edition through the [NTUA course listing](https://www.ece.ntua.gr/en/education/undergraduate/courses?courseId=3399) and [Helios course](https://helios.ntua.gr/course/view.php?id=1015), subject to authorized access. They are useful when comparing the implementation with the original assignment and play no role at runtime.
